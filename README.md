# OUD-CAPTURE
Resources for Capture-Recapture (CRC) and Bayesian Integrated Abundance (BIA) models for estimating opioid use disorder (OUD)

There are three folders "CRC Massachusetts", "CRC Washington State", and "Prescriptions Data". 

"CRC Massachusetts" contains CSV files with data related to a published study estimating the prevalence of opioid use disorder in Massachusetts from 2011 to 2015. 

"CRC Washington State" contains a CSV file `CRCsimdata_WA.csv` to use in code `CRCanalysis_toydata_WA_code.R` to generate CRC estimates 

"Prescriptions Data" contains a R file `bupe_oud_definition.R` that links to prescription database, filters the data to buprenorphine prescription related to OUD.
